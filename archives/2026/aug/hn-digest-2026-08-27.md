## 4. [We found a division by zero bug in FFmpeg with a vibecoded fuzzer](https://news.ycombinator.com/item?id=49468642) (↑123, 💬94)
**Article:** This FFmpeg issue reports a divide-by-zero crash (SIGFPE) in the VPK demuxer triggered by a crafted 21-byte input. The root cause is that `vpk_read_packet` divides by `nb_channels` without a zero check; a malformed header can set it to zero after validation diverges between probe/header and packet-read paths. A guard clause fix and regression test are included.

**Comments:** Commenters debated whether this counts as a real FFmpeg bug (some argued it only occurs via a custom AVIO path) and whether vibecoded fuzzers are genuinely noteworthy — with replies noting that cheap, persistent AI-driven fuzzing is a real advantage. Others discussed static analysis approaches to divide-by-zero (refinement types, range analysis, false-positive tradeoffs), and some suggested FFmpeg should be built with allow-lists of needed formats instead of the kitchen sink.
