## 19. [Samsung's Processing-in-Memory (PIM)](https://news.ycombinator.com/item?id=49487341) (↑227, 💬89)
**Article:** Samsung's LPDDR5X-PIM places MAC compute units in each of 16 DRAM banks, exploiting 614 GB/s internal bandwidth versus 76.8 GB/s externally, while staying within the standard LPDDR5X protocol via special row addresses that act like MMIO. Each PIM block supports low-precision formats (INT8/FP8/INT4) at roughly 2.4 TOPS per chip. **Comments:** Many commenters were skeptical, noting PIM has been "the future" for decades with few successful products, though some identified LLM inference as the likely killer app. Technical debates covered data movement for matrix multiplication, virtual memory and OS implications, heat dissipation, security risks, and memory encryption, while a few optimists hoped it would enable cheap home LLM machines.
