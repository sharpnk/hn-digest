## 11. [Implementation of GCC's Nested Functions (vs. C++ Lambdas)](https://news.ycombinator.com/item?id=49575766) (↑43, 💬3)
**Article:** The author explains how GCC implements nested functions by collecting all parent variables accessed by the nested function into a synthetic frame structure, passing a hidden pointer to that structure as an argument. This decouples nested functions from frame-pointer-based mechanisms and lets generic optimizers handle the synthetic struct. The article then compares this to C++ lambda implementation, concluding that GCC's nested functions are a semantic subset of lambdas with fundamentally similar implementation approaches.

**Comments:** The top commenter argues the article omits the core complexity—using nested functions as bare function pointers requires trampolines or special ABI support, whereas C++ lambdas avoid this issue because they're passed as objects, not function pointers. Overall consensus is that the interesting hard part is function pointer conversion, not the basic frame-passing mechanism the article focuses on.
