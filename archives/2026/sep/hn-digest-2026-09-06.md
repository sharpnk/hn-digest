## 2. [Show HN: Mador – Make any DOM reactive with a tiny 80-line Proxy state tuple](https://news.ycombinator.com/item?id=49590738) (↑36, 💬12)
**Article:** Mador is a tiny (~855-byte minified) reactive DOM runtime that uses a Proxy-based `[read, write]` state tuple to bind state directly to existing DOM selectors, with no components, templates, or virtual DOM. Reads track which state properties a binding accesses, so effects rerun only on relevant changes, and writes are batched and automatically cleaned up when bound elements disappear.

**Comments:** Commenters propose more readable API variants and ask how Mador differs from existing signal primitives like preact/signals or Vue reactivity. The author says it was mostly for fun and to test how small a zero-dependency reactive system could be, while others push back that preact/signals-core is likewise tiny and dependency-free, making the README's framework-vs-Mador framing a false dilemma.
