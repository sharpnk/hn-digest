## 6. [Show HN: A working Nintendo in ~1GB of Qwen weights](https://news.ycombinator.com/item?id=50306442) (↑151, 💬99)
**Article:** nesformer is a GitHub project that compiles the NES 6502 CPU, 2 KB work RAM, and NROM cartridge ROM into the weights of a stock Qwen3.5 checkpoint, with no training involved. The model predicts CPU execution one token at a time while a host program handles rendering, controller input, and vblank interrupts. It supports NROM games, runs far slower than real hardware, and its bundled tests are checked against a conventional 6502 emulator.

**Comments:** Commenters are split between admiration for the technical feat—especially exact emulation via conformance tests and the use of model state as memory—and skepticism that it is a slow, impractical stunt. Many discuss LLM determinism, the possibility of compiling VMs or operating systems into weights, and the large efficiency gap versus ordinary software. Some criticize the AI-assisted build process or the imprecise “Nintendo” title, while others defend the project as fun and thought-provoking.
